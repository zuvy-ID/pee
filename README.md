# ⏳ Waktu & Rasa

Website interaktif berisi lagu-lagu dengan kenangan spesial.

## ✨ Fitur
- 3D Card dengan transisi halus
- Background glow orbs & particles
- Music visualizer bar
- Auto-slide (pause saat interaksi)
- Keyboard & swipe support
- Modal cerita di balik lagu

## 🚀 Cara Pakai
1. Clone repo ini
2. Masukkan file MP3 ke folder `assets/`
3. Buka `index.html` di browser
